# Lab 4 Angular v1: products without login

Product CRUD (list, search, create, edit, delete) against the open FastAPI routes at `/products`.

```cmd
npm install
npm start
```

Open http://localhost:4200. The FastAPI API must be running at the `apiUrl` in `src/environments/environment.ts` (default `http://localhost:8121`).

Needs Node.js 22.22.3+ or 24.15+ (Angular 22). Full guide: section 11 of the main `README.md`.
